# Vehicle Manager

Приложение можно посмотреть по ссылке https://drivegosling.github.io/react-task/

## Описание

Для сортировки используйте заголовки таблицы Год / Цена.

## Технологии

- React
- TypeScript
- HTML/CSS
- Zustand
- Axios

## Установка и использование

Клонируйте репозиторий:
```
git clone git@github.com:driveGosling/react-task.git
```

Перейдите в папку проекта:
```
cd react-task
```
Установите зависимости:
```
npm install
```
Запустите локальный сервер разработки:
```
npm run start
```
